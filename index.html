🧭 What This Application Does

ai-iso-skill is a companion skill for Claude, the AI assistant. When you ask Claude to draw a figure in an isometric style, this skill guides it to produce a clean, interactive picture. Isometric drawings show objects at an angle so they look three-dimensional, which makes them ideal for diagrams, game maps, floor plans, technical illustrations, and teaching material.

The result is delivered as a single HTML file. That file contains the whole figure, its colors, and its interactive behavior. You do not need to install extra libraries, connect to a server, or link any other file. You simply open the HTML file in a normal web browser such as Chrome, Edge, or Firefox, and the figure appears.

Interactive means the figure responds to you. You can move your mouse over parts of the drawing and see them react, click sections to highlight them, or rotate and inspect details. Because the output is built with SVG, the shapes stay sharp at any size and can be zoomed without becoming blurry.

✨ Why People Use It

  • One file only. Everything is packed into a single HTML document, so sharing is as simple as sending an email attachment.
  • Made for Claude. The skill plugs into Claude and Claude Code, so you can ask for a figure in plain language.
  • Interactive by default. Hover, click, and highlight effects are built into the drawing instead of being added later.
  • Sharp SVG graphics. Figures stay crisp when printed, enlarged, or viewed on a high-resolution screen.
  • No installation complexity. You do not need a toolkit or a development environment to open the result.

🖱️ Using the Figures

Once a figure is open in your browser, most of the interaction happens with the mouse. Hovering over a shape can change its color or raise a small label. Clicking a shape can select it or reveal more detail. Some figures include simple controls near the edge of the drawing for adjusting the view.

Because the whole drawing lives in one file, you can copy it to a USB stick, attach it to an email, or place it on a shared drive. Anyone who receives it can open it in a browser and see the same interactive figure, with no extra software and no setup on their side.

To keep a copy as an image, use the print option in your browser and choose Save as PDF. The vector shapes stay sharp in the PDF, which is handy for reports, slides, and printed handouts.

🛠️ Common Questions

The page looks empty after I click the link

Scroll down. The releases page lists versions in sections, and the newest one sits at the top. If nothing appears at all, refresh the page or try a different browser.

Windows blocked the file

Windows sometimes flags files downloaded from the internet. Open the file's properties, look for the Unblock checkbox near the bottom, tick it, and click Apply. Then try opening the file again.

The HTML file opens as text instead of a drawing

This means Windows opened the file in a text editor. Right-click the file, choose Open with, and select your browser. You can also set the browser as the default for HTML files so future double-clicks work correctly.

Claude does not seem to use the skill

Check that the skill files sit in the exact folder your Claude setup expects, and that the folder name matches what the release page shows. Restart Claude after moving files so it notices the change.

The figure is cut off on my screen

Press Ctrl and minus a few times to zoom out, or make the browser window larger. You can also press F11 for full-screen view, which gives the drawing more room.

Can I edit the drawing myself?

Yes. The HTML file is plain text. Open it in Notepad or any text editor and you will see the shapes, colors, and labels written in a readable form. Change a color value or a label, save the file, and refresh the browser to see the update. Keep a backup copy first so you can always return to the original.

📁 Keeping Things Organized

Over time you may collect several figures. A simple folder structure keeps them manageable. Create one main folder named ai-iso-skill, then a subfolder for each project or theme, such as office-scenes or game-maps. Give each HTML file a clear name that describes the drawing. This makes searching and sharing far easier than sorting through files named download or figure-final-final.

It also helps to keep the original release files untouched in their own folder. Treat that folder as your master copy. When you experiment with edits, work on a duplicate so the master stays clean.
